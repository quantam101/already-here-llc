# AZ-MVS Asset Inventory Project — Internal Cost Sheet

This is an internal estimate of the equipment/supplies to purchase and the mileage cost to execute the 24-site AZ-MVS asset inventory and 2D QR tagging project. It is **not** part of the client proposal; the proposal already includes travel/mobilization in the per-site rate.

---

## 1. Equipment & supplies to purchase (if not already owned)

| Item | Purpose | Est. Cost |
|---|---|---|
| Zebra ZD411 thermal-transfer label printer (203 dpi, USB/Ethernet/Bluetooth) | Print durable 1" × 2" QR asset labels on-site | $470–$500 |
| Zebra Z-Ultimate 4000T 1" × 2" polyester labels, 1 roll (~1,500 labels) | Asset-tag material; one roll covers the ~700 assets plus extras | $108 |
| Zebra 5095 resin ribbon, 2.36" × 984', single roll | Thermal-transfer ribbon for the label printer | $37 |
| Socket Mobile SocketScan S740 2D/1D Bluetooth barcode scanner | Scan QR codes during inventory and QA | $370 |
| Rugged Android smartphone or tablet (optional if using personal phone) | Run data-capture forms, camera, and mobile scanner app | $0 if existing; otherwise $200–$400 |
| Carrying case / field bag for printer, scanner, and supplies | Transport gear between sites | $50 |
| Portable power bank (20,000 mAh) | Keep phone/scanner charged all day | $30 |
| Screen protectors, cleaning wipes, small flashlight, blue painter’s tape | Misc field supplies | $30 |
| **Total one-time equipment + initial supplies** | | **~$1,095–$1,525** |

### Notes

- The label printer is a one-time capital purchase. Already Here can reuse it on every tagging job.
- The scanner is 2D-capable so it reads the QR codes we print. The SocketScan S740 also works with phones/tablets via Bluetooth.
- If you already own a thermal-transfer printer, a compatible 2D scanner, or a suitable mobile device, subtract those line items.
- For a two-technician crew, add a second scanner (~$370) so each tech has one.

## 3. Mileage cost — Arizona state rate

**Arizona personal-vehicle mileage reimbursement rate:** **$0.67 per mile**  
(Source: State of Arizona Accounting Manual, Section 95, effective 01/27/25)

**Base / starting point:** Already Here LLC, 429 N 18th Dr, Phoenix, AZ 85007

### Assumed routing

- 12 field days, **2 sites per day**, returning to base each day.
- Driving distances computed with OSRM (OpenStreetMap routing) for the most efficient daily loop.
- Distances are round-trip miles from base through the day’s sites and back to base.

### Alternative grouping (if doing 3 sites/day)

If the sites are grouped into 8 days of 3 sites each, the optimized routing drops to roughly **479.7 miles**, which at $0.67/mile is **$321.40**. The 2-site/day schedule is used above as the conservative (and more realistic for first-pass inventory) estimate.
